# Example data

- `sample_postings.csv`: real public Toronto job postings, checked November 5–8, 2026. It holds short excerpts of
  pay, schedule and requirement lines, plus links to the employers' own pages.
- `sample_applications.csv`: a **fictional** applications journal with made-up employers. It only demonstrates the
  search analytics and is not a real result.
- `profile.example.json`: a **fictional** student profile. Copy it and edit it to use your own constraints.
- `resume.example.txt`: a **fictional** plain-text résumé for the keyword matcher.

Keep your real journal in `data/applications.csv`. The `data/` folder is git-ignored so it stays private.
